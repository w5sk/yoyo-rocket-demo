# Выбранный авиационный дизайн

Реализован по выбранному мобильному эскизу: тёмное увеличенное поле, контрастный красный самолёт, одна панель ставки. История оформлена одной нейтральной полосой; последний коэффициент белый, остальные серые. Реальные завершённые раунды остаются кликабельными и открывают проверку. Пустая история не подменяется выдуманными результатами.

В доступной ветке репозитория нет общей оболочки yoyo.market. Навигация повторяет визуальные принципы присланных скриншотов: графит, белые подписи, синие акценты, небольшие радиусы. Кнопка Yoyo открывает меню с настоящими ссылками на маркет и игры; настройки и помощь работают внутри демо. На компьютере ссылки также доступны в шапке.

Мобильный первый экран состоит из шапки, истории, гибкой сцены и ставки снизу. Список игроков находится ниже. На компьютере список слева заменяется чатом справа. Музыки нет, игровые звуки доступны в настройках (и в шапке компьютера).

## Ресурс

`public/plane-flight.webp` создан встроенным image_gen, затем оптимизирован sharp-cli до 640 px / 44 664 байт с сохранением прозрачности. Полный запрос сохранён в `plane-prompt.json`. Это новый ресурс, а не скопированная модель Aviator.

## Проверка

- TypeScript и production-сборка пройдены.
- 27 модульных тестов пройдены.
- 19 сценариев компьютера, Pixel 7 и iPhone 13 пройдены с повтором исправленных случаев.
- Дополнительные проверки RU/EN на Galaxy S9+, широком Android, iPhone SE, iPhone 13 и iPhone 13 Pro Max: 10/10.
- Переключение языков с активной ставкой, отмена, ручной и автоматический вывод, очередь, чат, меню Yoyo.
- Диапазон ширин 320–1920 px, короткие и альбомные экраны. Проверено изменение высоты браузера.
- Использованы мобильный UA, DPR, касания и WebKit для iPhone. Это эмуляция, не проверка на физических устройствах. WebKit под Windows не воспроизводит Web Audio: для него проверен безопасный отказ; звук проверен в Chromium и модульных тестах.

Снимки сняты из работающей игры. Для воспроизводимости только сценарий съёмки использует нулевой seed и ускоренное время; production-код не содержит такого режима. Переснять: `node scripts/capture-aviation.mjs` при работающем Vite на порту 5173.
