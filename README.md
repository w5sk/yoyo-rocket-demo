# Yoyo Rocket demo

- Russian: https://w5sk.github.io/yoyo-rocket-demo/?lang=ru
- English: https://w5sk.github.io/yoyo-rocket-demo/?lang=en

The game fills the browser viewport. Bet controls sit at the bottom and the flight scene uses the remaining height. Charcoal surfaces, dark fields and rectangular blue buttons follow the service reference. Short portrait screens use compact controls; landscape places the two bet panels beside each other. Safe-area insets are respected.

Six complete Android/iPhone profiles are checked in Russian and English using Chromium and WebKit, touch input and device pixel screenshots. Tests also resize the available height and verify no extra page scrolling. These are emulated profiles, not physical-device certification.

Virtual demo coins only. No payments or real money. The current version loads the 58 KB WebP sprite; previous asset URLs remain available for cached clients.
