# Yoyo Rocket demo

Play the mobile-first prototype in your browser:

- Russian: https://w5sk.github.io/yoyo-rocket-demo/?lang=ru
- English: https://w5sk.github.io/yoyo-rocket-demo/?lang=en

Proportionally scaled mobile reference layout (320-480 px), three cloud layers and brighter stars: single header row, multiplier strip, wide scene and two stacked framed bet panels. Language and balance reset are in settings; history and fairness open from icons. Blue controls, automatic cash-out, lightweight sky-blue character and original sounds. Virtual demo coins only. No payments or real money.

This repository contains the compiled static demo. Source revision: 6da7b0ce10caa6768a345550132f1d8c23ba7ac0.

Previous asset URLs are retained for browsers with cached versions. The current version loads the 58 KB WebP sprite.

Mobile QA covers six complete Android/iPhone profiles in Russian and English, using Chromium and WebKit with touch input and device pixel screenshots. Static Golos Text weights keep typography consistent in the tested engines. These are emulated profiles, not physical-device certification.
