# Yoyo Rocket demo

Play the mobile-first prototype in your browser:

- Russian: https://w5sk.github.io/yoyo-rocket-demo/?lang=ru
- English: https://w5sk.github.io/yoyo-rocket-demo/?lang=en

Mobile reference layout: single header row, multiplier strip, wide scene and two stacked framed bet panels. Language and balance reset are in settings; history and fairness open from icons. Blue controls, automatic cash-out, lightweight sky-blue character and original sounds. Virtual demo coins only. No payments or real money.

This repository contains the compiled static demo. Source revision: f01bcc45a70e9e6d9fb153c20a1d2a65986d3c3b.

Previous asset URLs are retained for browsers with cached versions. The current version loads the 58 KB WebP sprite.
