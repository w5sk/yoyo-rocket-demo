# Yoyo Rocket demo

- Russian: https://w5sk.github.io/yoyo-rocket-demo/?lang=ru
- English: https://w5sk.github.io/yoyo-rocket-demo/?lang=en

A viewport-filling crash game with charcoal surfaces, rectangular blue controls and a blue jetpack pilot. Desktop shows player bets on the left and an optional chat on the right. On mobile, the players button opens a compact scene with the bet list below the controls; chat opens full screen.

All / My / Top filters, previous rounds, own bets and next-round queues follow the demo engine. The other 28 participants are clearly labeled simulated activity and never affect the wallet or round results. Chat is a local demo: 160 characters per message, up to 60 messages, no communication between visitors or persistence after reload.

Auto cash-out targets from 1.00 to 999.99 fit without horizontal input scrolling. Six complete Android/iPhone profiles are checked in Russian and English using Chromium/WebKit and touch input. These are emulated profiles, not physical-device certification. 24 unit tests and 21 browser scenarios passed locally. Lighthouse mobile: performance 98, accessibility 100, LCP 2.4 s, CLS 0.

Virtual demo coins only. No payments or real money. The pilot sprite is a 58 KB WebP; previous asset URLs remain available for cached clients.
