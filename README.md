# Yoyo Rocket demo

Play the mobile-first prototype in your browser:

- Russian: https://w5sk.github.io/yoyo-rocket-demo/?lang=ru
- English: https://w5sk.github.io/yoyo-rocket-demo/?lang=en

Minimal mobile-first interface: balance, multiplier and two bet panels. Rules, history and fairness open from icons. Blue controls, automatic cash-out, lightweight sky-blue character and original sounds. Virtual demo coins only. No payments or real money.

This repository contains the compiled static demo. Source revision: b3409db5277063943f270284e31037708ab273c2.

Previous asset URLs are retained for browsers with cached versions. The current version loads the 58 KB WebP sprite.
